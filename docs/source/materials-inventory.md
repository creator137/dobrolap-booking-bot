## Конфиденциальность

В исходной переписке есть телефоны, банковские реквизиты, имя получателя платежа и чек. Они намеренно не перенесены в документацию. Сырой Telegram-экспорт не предназначен для Git и должен храниться отдельно с ограниченным доступом. Для production секреты следует хранить в переменных окружения или другом закрытом хранилище.

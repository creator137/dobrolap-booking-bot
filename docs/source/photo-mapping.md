Все настроенные `photo_paths`, включая привязки к виду питомца и строке календаря, проверяются при загрузке каталога. Фото VIP+ `16` показывается только для предполагаемой строки `Домик 2 этаж`; внешний и внутренний виды уличного вольера №2 (`18` и `23`) — только для строки №2. Три новых уличных фото показываются как общая галерея типа для всех трёх строк. Фото `31` показывается только при подборе А+А; старый кадр `04` по-прежнему не показывается, как и кадр крытого вольера `17`: их точная привязка не подтверждена. Для «Стандарт M» и «Стандарт L» фото показывают тип размещения, а конкретный бокс подтверждает владелец. Названия копий — рабочие идентификаторы, не утверждённые коммерческие названия.
